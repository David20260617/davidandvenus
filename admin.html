手机端 · GitHub 同步

连接到 GitHub

第一次需要填一次，之后会存在这台手机上，打开即用。

Token 申请：GitHub → 头像 → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token，只勾选本仓库的 Contents: Read and write，有效期选 90 天。
令牌只存在这台手机的浏览器里，我不会上传到任何地方。
注意：必须在网站部署后的真实网址（https://…）打开本工具，不要用本地文件双击打开，否则浏览器会因跨域限制无法连接 GitHub。

作品

点一幅作品可改标题、尺寸、价格和图片。改完点“保存并发布”，网站会自动更新（约 1–2 分钟）。
